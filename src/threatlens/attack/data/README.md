# Bundled ATT&CK data

`enterprise-attack.json` is a compact list of MITRE ATT&CK Enterprise tactics and
techniques, generated by `scripts/gen_attack_techniques.py` from MITRE's official
STIX bundle (https://github.com/mitre-attack/attack-stix-data). The file records
the ATT&CK version, the source URL and the SHA-256 of the bundle it came from.

ThreatLens never downloads ATT&CK data at runtime. To update:

```bash
python scripts/gen_attack_techniques.py --version <new version>
```
